Имя файла final_final.ipynb плохо помогает проверке, потому что оно неинформативно, нарушает воспроизводимость и мешает организации работы.
В открытый репозиторий нельзя выкладывать секретные ключи, пароли и любые конфиденциальные данные, которые могут дать злоумышленникам доступ к вашим системам или пользовательской информации.
Файл README должен объяснять, что делает проект, как его запустить и как им пользоваться.
